**Create a `useHeartbeat` custom React hook in `app/hooks/useHeartbeat.ts` that polls your `/api/cron/heartbeat` endpoint on an interval and exposes `{ status, lastChecked, error }` to any component.**

Today's focus: **Hooks — building a custom React hook that surfaces real-time backend health**

Here's a starting implementation:

```ts
// app/hooks/useHeartbeat.ts
"use client";

import { useEffect, useState } from "react";

type HeartbeatStatus = "ok" | "degraded" | "loading" | "error";

interface HeartbeatState {
  status: HeartbeatStatus;
  lastChecked: Date | null;
  error: string | null;
}

export function useHeartbeat(intervalMs = 30_000): HeartbeatState {
  const [state, setState] = useState<HeartbeatState>({
    status: "loading",
    lastChecked: null,
    error: null,
  });

  useEffect(() => {
    async function check() {
      try {
        const res = await fetch("/api/cron/heartbeat");
        const data = await res.json();
        setState({ status: data.status, lastChecked: new Date(), error: null });
      } catch (err) {
        setState((prev) => ({ ...prev, status: "error", error: String(err) }));
      }
    }

    check(); // run immediately on mount
    const id = setInterval(check, intervalMs);
    return () => clearInterval(id); // cleanup on unmount
  }, [intervalMs]);

  return state;
}
```

Then use it in `app/page.tsx`:

```tsx
import { useHeartbeat } from "./hooks/useHeartbeat";

export default function HomePage() {
  const { status, lastChecked } = useHeartbeat();
  return (
    <main>
      <p>Webhook status: <strong>{status}</strong></p>
      {lastChecked && <p>Last checked: {lastChecked.toLocaleTimeString()}</p>}
    </main>
  );
}
```

**Why this matters:** Custom hooks are how you encapsulate stateful logic that talks to your backend — polling, WebSockets, event subscriptions. The pattern here (`useEffect` with `setInterval` + cleanup) is the foundational shape for any hook that needs to sync with an external source. Once you have `useHeartbeat`, you can build on it: add optimistic updates, back-off on errors, or swap polling for a WebSocket connection from the same hook interface without changing the component.
