## Suggested next step
**Create a custom React hook at `app/hooks/useHeartbeat.ts` that polls `/api/cron/heartbeat` on an interval and renders the live status on the home page — this is the pattern that connects your backend event handlers to something users actually see.**

**Step 1 — Create `app/hooks/useHeartbeat.ts`:**

```ts
import { useEffect, useState } from "react";

type HeartbeatStatus = "ok" | "degraded" | "unknown" | "loading";

interface HeartbeatData {
  status: HeartbeatStatus;
  checkedAt: string | null;
}

export function useHeartbeat(intervalMs = 30_000): HeartbeatData {
  const [data, setData] = useState<HeartbeatData>({
    status: "loading",
    checkedAt: null,
  });

  useEffect(() => {
    async function check() {
      try {
        const res = await fetch("/api/cron/heartbeat");
        if (!res.ok) throw new Error("non-2xx");
        const json = await res.json();
        setData({ status: json.status ?? "ok", checkedAt: new Date().toISOString() });
      } catch {
        setData((prev) => ({ ...prev, status: "degraded" }));
      }
    }

    check();
    const id = setInterval(check, intervalMs);
    return () => clearInterval(id);
  }, [intervalMs]);

  return data;
}
```

**Step 2 — Use it in `app/page.tsx`:**

```tsx
"use client";
import { useHeartbeat } from "./hooks/useHeartbeat";

export default function Home() {
  const heartbeat = useHeartbeat();

  return (
    <main style={{ padding: "2rem", fontFamily: "monospace" }}>
      <h1>beginloops</h1>
      <p>
        Webhook status:{" "}
        <strong>{heartbeat.status}</strong>
        {heartbeat.checkedAt && (
          <span style={{ color: "#888", marginLeft: "0.5rem" }}>
            (checked {new Date(heartbeat.checkedAt).toLocaleTimeString()})
          </span>
        )}
      </p>
    </main>
  );
}
```

**Why this matters:** React hooks are the bridge between your backend event handlers and your UI. `useHeartbeat` demonstrates the core pattern: `useEffect` fires once (and on interval), `fetch` calls your own API route, and `useState` holds the result so React re-renders when it changes. The same shape — poll an endpoint, display state — powers most real-time dashboards, status pages, and live feeds. Once this clicks, adding `useWebhookEvents`, `useCronStatus`, or any other live-data hook is just a variation on the same three lines: fetch, set state, clean up.
