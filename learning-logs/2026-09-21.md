Today's focus: **Hooks — custom React hook**

Your backend is running and logging, but the UI is still the default scaffold. The missing piece is a hook that bridges them. A custom hook encapsulates the `fetch`, the polling interval, and the loading/error states so your component stays clean.

Create `app/hooks/useHeartbeat.ts`:

```ts
"use client";

import { useEffect, useState } from "react";

interface HeartbeatResult {
  status: "ok" | "degraded" | null;
  timestamp: string | null;
  loading: boolean;
  error: string | null;
}

export function useHeartbeat(intervalMs = 10_000): HeartbeatResult {
  const [state, setState] = useState<HeartbeatResult>({
    status: null,
    timestamp: null,
    loading: true,
    error: null,
  });

  useEffect(() => {
    let cancelled = false;

    async function poll() {
      try {
        const res = await fetch("/api/cron/heartbeat");
        const data = await res.json();
        if (!cancelled) setState({ status: data.status, timestamp: data.timestamp, loading: false, error: null });
      } catch (err) {
        if (!cancelled) setState((s) => ({ ...s, loading: false, error: String(err) }));
      }
    }

    poll();
    const id = setInterval(poll, intervalMs);
    return () => { cancelled = true; clearInterval(id); };
  }, [intervalMs]);

  return state;
}
```

Then in `app/page.tsx`, import and use it:

```tsx
import { useHeartbeat } from "./hooks/useHeartbeat";

export default function Home() {
  const { status, timestamp, loading } = useHeartbeat();
  return (
    <main>
      <p>Heartbeat: {loading ? "checking…" : status}</p>
      {timestamp && <p>Last checked: {new Date(timestamp).toLocaleTimeString()}</p>}
    </main>
  );
}
```

**Why this matters:** `useEffect` with a `clearInterval` cleanup is the canonical React pattern for subscriptions and polling — if you skip the cleanup, the interval keeps firing after the component unmounts, causing memory leaks and stale-state updates. The `cancelled` flag handles the race condition where a slow fetch resolves after the component unmounts. Once you've built this, the same pattern applies to any real-time data: websocket connections, SSE streams, or polling any API.
