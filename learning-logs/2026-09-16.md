Today's focus: **Hooks — connecting your cron + heartbeat back-end to a live UI**

Your back-end pipeline is complete: Vercel fires the cron, the heartbeat handler probes the webhook, and both log their results. The missing piece is a React hook that lets `app/page.tsx` show that status in real time.

Create `app/hooks/useHeartbeat.ts`:

```ts
"use client";
import { useEffect, useState } from "react";

interface HeartbeatStatus {
  status: "ok" | "degraded" | "unknown";
  timestamp: string | null;
  checks: { webhookEndpoint: "ok" | "unreachable" } | null;
}

export function useHeartbeat(intervalMs = 30_000): HeartbeatStatus {
  const [data, setData] = useState<HeartbeatStatus>({
    status: "unknown",
    timestamp: null,
    checks: null,
  });

  useEffect(() => {
    async function poll() {
      try {
        const res = await fetch("/api/cron/heartbeat");
        if (!res.ok) throw new Error(`${res.status}`);
        const json = await res.json();
        setData(json);
      } catch {
        setData((prev) => ({ ...prev, status: "degraded" }));
      }
    }

    poll();
    const id = setInterval(poll, intervalMs);
    return () => clearInterval(id);
  }, [intervalMs]);

  return data;
}
```

Then use it in `app/page.tsx`:

```tsx
"use client";
import { useHeartbeat } from "./hooks/useHeartbeat";

export default function Home() {
  const { status, timestamp } = useHeartbeat();
  const color = status === "ok" ? "text-green-500" : status === "degraded" ? "text-red-500" : "text-zinc-400";

  return (
    <main className="flex flex-col items-center justify-center min-h-screen gap-4">
      <h1 className="text-2xl font-semibold">beginloops</h1>
      <p className={`text-sm font-mono ${color}`}>
        webhook {status} {timestamp ? `· ${new Date(timestamp).toLocaleTimeString()}` : ""}
      </p>
    </main>
  );
}
```

**Why this matters:** A hook that polls on an interval is the simplest pattern for real-time UI state — no WebSockets, no subscriptions, just `useEffect` + `setInterval` + cleanup. `return () => clearInterval(id)` is the critical line: it tears down the interval when the component unmounts so you don't accumulate timers across navigations. Once you have this running, you'll see the full loop live: cron fires → heartbeat probes webhook → hook fetches → UI updates.
