Today's focus: **Hooks (Custom React Hooks)**

The heartbeat cron already runs and returns a JSON payload like `{ status: "ok", timestamp: "...", checks: { webhookEndpoint: "ok" } }`. Right now that data goes nowhere — it's logged to the server and forgotten. A custom hook closes the loop: the UI asks the server on a timer, gets the payload, and re-renders when it changes. This is the React pattern for "poll an endpoint and keep the UI in sync."

**Step 1 — Create `hooks/useHeartbeat.ts`:**

```ts
import { useEffect, useState } from "react";

interface HeartbeatResult {
  status: "ok" | "degraded" | "loading" | "error";
  timestamp: string | null;
  checks: { webhookEndpoint: "ok" | "unreachable" } | null;
}

export function useHeartbeat(intervalMs = 30_000): HeartbeatResult {
  const [result, setResult] = useState<HeartbeatResult>({
    status: "loading",
    timestamp: null,
    checks: null,
  });

  useEffect(() => {
    async function poll() {
      try {
        const res = await fetch("/api/cron/heartbeat");
        if (!res.ok) throw new Error("non-ok response");
        const data = await res.json();
        setResult({ status: data.status, timestamp: data.timestamp, checks: data.checks });
      } catch {
        setResult((prev) => ({ ...prev, status: "error" }));
      }
    }

    poll(); // fire immediately on mount
    const id = setInterval(poll, intervalMs);
    return () => clearInterval(id); // cleanup on unmount
  }, [intervalMs]);

  return result;
}
```

**Step 2 — Use it in `app/page.tsx`:**

```tsx
"use client"; // hooks require a Client Component
import { useHeartbeat } from "@/hooks/useHeartbeat";

export default function Home() {
  const { status, timestamp, checks } = useHeartbeat(30_000);

  return (
    <main>
      <h1>beginloops</h1>
      <p>Status: <strong>{status}</strong></p>
      <p>Webhook endpoint: {checks?.webhookEndpoint ?? "—"}</p>
      <p>Last checked: {timestamp ? new Date(timestamp).toLocaleTimeString() : "…"}</p>
    </main>
  );
}
```

**Why this matters:** Custom hooks are React's answer to "reusable stateful logic." Instead of putting the `fetch` + `setInterval` directly in the component, you extract it to `useHeartbeat` — now any component can call the hook and get live status without duplicating the polling logic. This same pattern works for WebSocket connections, EventSource streams, and any other "subscribe and react" data flow. Once you understand it here, you'll recognize it everywhere.

**What to notice while building it:** Watch the browser's Network tab — you'll see a `GET /api/cron/heartbeat` request fire every 30 seconds. The `return () => clearInterval(id)` line is the cleanup function: React calls it when the component unmounts, preventing a memory leak. Remove it temporarily and watch the requests continue in the background even after navigating away — then add it back and watch them stop.
