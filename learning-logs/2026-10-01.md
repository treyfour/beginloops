Today's focus: **Hooks — connecting your backend heartbeat to the frontend**

Your heartbeat route is running and returning data, but nothing shows it to a user. A custom React hook is the standard pattern for wrapping a fetch-on-interval — it keeps the polling logic in one place and lets any component subscribe to the live status.

Create `app/hooks/useHeartbeat.ts`:

```ts
"use client";

import { useEffect, useState } from "react";

interface HeartbeatStatus {
  status: "ok" | "degraded" | "loading";
  timestamp: string | null;
  checks: { webhookEndpoint: "ok" | "unreachable" } | null;
}

export function useHeartbeat(intervalMs = 30_000) {
  const [data, setData] = useState<HeartbeatStatus>({
    status: "loading",
    timestamp: null,
    checks: null,
  });

  useEffect(() => {
    async function poll() {
      try {
        const res = await fetch("/api/cron/heartbeat");
        if (!res.ok) throw new Error("non-ok response");
        const json = await res.json();
        setData(json);
      } catch {
        setData({ status: "degraded", timestamp: new Date().toISOString(), checks: null });
      }
    }

    poll(); // run immediately on mount
    const id = setInterval(poll, intervalMs);
    return () => clearInterval(id); // cleanup when unmounted
  }, [intervalMs]);

  return data;
}
```

Then use it anywhere in `app/page.tsx`:

```tsx
import { useHeartbeat } from "./hooks/useHeartbeat";

// inside your component:
const heartbeat = useHeartbeat();
// heartbeat.status is "ok" | "degraded" | "loading"
```

**Why this matters:**
- The `useEffect` + `setInterval` + cleanup pattern is how React handles recurring side effects — learning it here applies to any polling scenario (live scores, dashboards, background jobs).
- Returning the cleanup function (`() => clearInterval(id)`) prevents memory leaks when the component unmounts — a common React bug when you skip it.
- The `"loading"` initial state makes your UI show a spinner instead of flashing stale data on first render.

Once this hook works, you have all three layers wired: cron fires the heartbeat → webhook receives the ping → React hook polls and displays the result.
