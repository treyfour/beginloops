Today's focus: **Hooks — writing a custom React hook that bridges your server infrastructure to the UI**

Your heartbeat endpoint already runs on a schedule server-side. A custom hook gives the client the same data on demand, live, without you having to wire up state and intervals everywhere. Here's the full implementation:

```ts
// app/hooks/useHeartbeat.ts
"use client";
import { useEffect, useState } from "react";

type Status = "ok" | "degraded" | "loading" | "error";

interface HeartbeatState {
  status: Status;
  timestamp: string | null;
  checks: Record<string, string> | null;
}

export function useHeartbeat(intervalMs = 30_000): HeartbeatState {
  const [state, setState] = useState<HeartbeatState>({
    status: "loading",
    timestamp: null,
    checks: null,
  });

  useEffect(() => {
    async function ping() {
      try {
        const res = await fetch("/api/cron/heartbeat");
        if (!res.ok) {
          setState({ status: "error", timestamp: new Date().toISOString(), checks: null });
          return;
        }
        const data = await res.json();
        setState({
          status: data.status,
          timestamp: data.timestamp,
          checks: data.checks ?? null,
        });
      } catch {
        setState({ status: "error", timestamp: new Date().toISOString(), checks: null });
      }
    }

    ping(); // fire immediately on mount
    const id = setInterval(ping, intervalMs);
    return () => clearInterval(id); // clean up on unmount
  }, [intervalMs]);

  return state;
}
```

Then use it in any component — for example a status badge in `app/page.tsx`:

```tsx
// app/page.tsx (add this somewhere in your UI)
import { useHeartbeat } from "@/app/hooks/useHeartbeat";

function ServerStatus() {
  const { status, timestamp } = useHeartbeat();

  const color =
    status === "ok" ? "text-green-500" :
    status === "degraded" ? "text-yellow-500" :
    status === "loading" ? "text-gray-400" : "text-red-500";

  return (
    <p className={`text-sm font-mono ${color}`}>
      ● {status} {timestamp ? `· ${new Date(timestamp).toLocaleTimeString()}` : ""}
    </p>
  );
}
```

**Why this matters:** Custom hooks are the React pattern for encapsulating stateful logic — the `useState` + `useEffect` + `setInterval` combo is the same skeleton you'll reuse for anything that polls: a job queue, a deploy status, a price feed. You also see the cleanup return (`return () => clearInterval(id)`) which prevents memory leaks when the component unmounts. This hook is immediately useful: drop `<ServerStatus />` into your layout and you have a live health indicator powered by the cron infrastructure you already built.
