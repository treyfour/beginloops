Today's focus: **Hooks — writing your first custom React hook tied to your real API**

You already have a heartbeat endpoint that tells you whether your webhook is healthy. The missing piece is a way to *show* that status in your UI without cluttering a component with fetch logic. That's exactly what custom hooks are for:

```ts
// app/hooks/useHeartbeat.ts
"use client";

import { useEffect, useState } from "react";

type HeartbeatStatus = "ok" | "degraded" | "loading" | "error";

interface HeartbeatResult {
  status: HeartbeatStatus;
  timestamp: string | null;
  loading: boolean;
}

export function useHeartbeat(intervalMs = 30_000): HeartbeatResult {
  const [status, setStatus] = useState<HeartbeatStatus>("loading");
  const [timestamp, setTimestamp] = useState<string | null>(null);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    async function poll() {
      try {
        const res = await fetch("/api/cron/heartbeat");
        const data = await res.json();
        setStatus(data.status ?? "error");
        setTimestamp(data.timestamp ?? null);
      } catch {
        setStatus("error");
      } finally {
        setLoading(false);
      }
    }

    poll(); // fire immediately on mount
    const id = setInterval(poll, intervalMs);
    return () => clearInterval(id); // cleanup on unmount
  }, [intervalMs]);

  return { status, timestamp, loading };
}
```

Then use it in any component:
```tsx
// app/page.tsx (or any Client Component)
import { useHeartbeat } from "@/hooks/useHeartbeat";

export default function Home() {
  const { status, timestamp, loading } = useHeartbeat();
  if (loading) return <p>Checking system status…</p>;
  return <p>Webhook: {status} · last checked {timestamp}</p>;
}
```

**Why this matters:** A custom hook is just a function that starts with `use` and calls other hooks — it's how React lets you share stateful logic across components. This one wraps `useEffect` + `setInterval` for polling, which is a pattern you'll use constantly: live status checks, presence indicators, real-time dashboards. Once you've written one hook, the mental model clicks for all of them.

The `clearInterval` in the cleanup function is the key insight — without it, every component mount would add a new timer and you'd spiral into infinite fetches.
