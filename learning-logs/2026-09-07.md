Today's focus: **React Hooks — turning your heartbeat endpoint into a live UI widget**

You've built a backend heartbeat that reports `ok` or `degraded`. Right now nothing reads it in the browser. A custom React hook is the idiomatic Next.js way to package that polling logic so any component can subscribe to it.

**Create `app/hooks/useHeartbeat.ts`:**

```ts
"use client";

import { useState, useEffect } from "react";

interface HeartbeatStatus {
  status: "ok" | "degraded" | "loading" | "error";
  timestamp: string | null;
  checks: { webhookEndpoint: "ok" | "unreachable" } | null;
}

export function useHeartbeat(intervalMs = 30_000): HeartbeatStatus {
  const [state, setState] = useState<HeartbeatStatus>({
    status: "loading",
    timestamp: null,
    checks: null,
  });

  useEffect(() => {
    async function poll() {
      try {
        const res = await fetch("/api/cron/heartbeat");
        if (!res.ok) throw new Error(`HTTP ${res.status}`);
        const data = await res.json();
        setState({ status: data.status, timestamp: data.timestamp, checks: data.checks });
      } catch {
        setState((prev) => ({ ...prev, status: "error" }));
      }
    }

    poll(); // run immediately on mount
    const id = setInterval(poll, intervalMs); // then every 30s
    return () => clearInterval(id); // cleanup on unmount
  }, [intervalMs]);

  return state;
}
```

**Use it in `app/page.tsx`:**

```tsx
"use client";

import { useHeartbeat } from "./hooks/useHeartbeat";

export default function Home() {
  const { status, timestamp } = useHeartbeat();

  const colors: Record<string, string> = {
    ok: "text-green-500",
    degraded: "text-yellow-500",
    error: "text-red-500",
    loading: "text-gray-400",
  };

  return (
    <main className="p-8">
      <h1 className="text-2xl font-bold mb-4">beginloops</h1>
      <div className={`font-mono ${colors[status]}`}>
        ● {status.toUpperCase()}
        {timestamp && (
          <span className="text-gray-400 text-sm ml-3">
            last checked {new Date(timestamp).toLocaleTimeString()}
          </span>
        )}
      </div>
    </main>
  );
}
```

**Three concepts to lock in:**

1. **`useEffect` cleanup** — the `return () => clearInterval(id)` is critical. Without it, every re-render starts a new interval and old ones keep firing after the component unmounts. The cleanup function runs when the component unmounts or before the next effect fires.

2. **Custom hooks are just functions** — `useHeartbeat` is a plain function that calls built-in hooks inside. React's rule is: hooks can only be called inside components or other hook functions (names starting with `use`). Packaging logic this way means any page can call `useHeartbeat()` without copy-pasting the fetch/interval code.

3. **Polling vs. push** — this is a *pull* pattern: the client asks for status every 30 seconds. For lower latency you'd replace the interval with a WebSocket or Server-Sent Events connection. Polling is simpler to start with and totally valid for a heartbeat widget that doesn't need sub-second updates.
