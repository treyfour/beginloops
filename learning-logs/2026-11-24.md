**Create `app/hooks/useHeartbeat.ts` — a custom React hook that polls `GET /api/status` on an interval and exposes the latest heartbeat state to any component.**

Today's focus: **Hooks — custom React hooks as the bridge between your API and your UI**

Right now, heartbeat data lives on the server. A custom hook is the idiomatic Next.js way to bring it into your components without scattering `fetch` calls and `setInterval` logic everywhere.

Create `app/hooks/useHeartbeat.ts`:

```ts
"use client";

import { useEffect, useRef, useState } from "react";

type HeartbeatStatus = {
  status: "ok" | "degraded" | "unknown";
  timestamp?: string;
  checks?: Record<string, string>;
  message?: string;
};

export function useHeartbeat(intervalMs = 10_000) {
  const [data, setData] = useState<HeartbeatStatus | null>(null);
  const [loading, setLoading] = useState(true);
  const timerRef = useRef<ReturnType<typeof setInterval> | null>(null);

  async function poll() {
    try {
      const res = await fetch("/api/status");
      const json = await res.json();
      setData(json);
    } catch {
      setData({ status: "unknown", message: "Failed to reach /api/status" });
    } finally {
      setLoading(false);
    }
  }

  useEffect(() => {
    poll();
    timerRef.current = setInterval(poll, intervalMs);
    return () => {
      if (timerRef.current) clearInterval(timerRef.current);
    };
  }, [intervalMs]);

  return { data, loading };
}
```

Then use it in `app/page.tsx`:

```tsx
import { useHeartbeat } from "@/app/hooks/useHeartbeat";

export default function Home() {
  const { data, loading } = useHeartbeat();
  if (loading) return <p>Checking system health…</p>;
  return (
    <main>
      <h1>System Status</h1>
      <p>Status: {data?.status ?? "unknown"}</p>
      {data?.timestamp && <p>Last heartbeat: {new Date(data.timestamp).toLocaleString()}</p>}
    </main>
  );
}
```

**Why this matters:** A custom hook is not magic — it's just a function that calls other hooks (`useState`, `useEffect`) and returns values. The pattern here — encapsulate a data-fetching side effect, expose clean state — is how every real React app separates concerns. Once you have `useHeartbeat`, you can drop live status into any page or layout with one line, swap the polling interval per page, and test the hook in isolation without touching any component. That reusability is the whole point of hooks.
