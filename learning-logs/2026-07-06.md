## Suggested next step
Create a custom React hook `useHeartbeat` in `app/hooks/useHeartbeat.ts` that polls your `/api/cron/heartbeat` endpoint on a set interval — this is how you wire the backend health loop into a live UI.

```ts
// app/hooks/useHeartbeat.ts
"use client";

import { useState, useEffect } from "react";

type HeartbeatResult = {
  status: "ok" | "degraded" | null;
  timestamp: string | null;
  loading: boolean;
  error: string | null;
};

export function useHeartbeat(intervalMs = 30_000): HeartbeatResult {
  const [result, setResult] = useState<HeartbeatResult>({
    status: null,
    timestamp: null,
    loading: true,
    error: null,
  });

  useEffect(() => {
    async function poll() {
      try {
        const res = await fetch("/api/cron/heartbeat");
        const data = await res.json();
        setResult({ status: data.status, timestamp: data.timestamp, loading: false, error: null });
      } catch (err) {
        setResult(prev => ({ ...prev, loading: false, error: String(err) }));
      }
    }

    poll(); // fire immediately on mount
    const id = setInterval(poll, intervalMs);
    return () => clearInterval(id); // cleanup on unmount
  }, [intervalMs]);

  return result;
}
```

Then use it in `app/page.tsx`:

```tsx
"use client";
import { useHeartbeat } from "./hooks/useHeartbeat";

export default function Home() {
  const { status, timestamp, loading } = useHeartbeat();
  return (
    <main>
      <p>Status: {loading ? "checking…" : status}</p>
      <p>Last check: {timestamp ?? "—"}</p>
    </main>
  );
}
```

**Why this matters:** Custom hooks are React's composable unit of side-effect logic. `useHeartbeat` encapsulates the fetch, the interval, and the cleanup — the component just calls one function and gets reactive state. This pattern (hook → fetch → interval) is the same shape used for WebSocket subscriptions, SSE streams, and polling-based live dashboards. The `return () => clearInterval(id)` cleanup function is the key concept: it runs when the component unmounts, preventing memory leaks. Once you internalize this cleanup pattern, you understand how React avoids resource leaks for any async side effect.
