Today's focus: **Webhooks (verifying that requests are genuine)**

Right now, anyone who knows your URL can POST any JSON to `/api/webhooks` and your handler will believe it came from GitHub. HMAC verification closes that gap: GitHub signs every request with a secret you both share, and your handler rejects anything with a bad or missing signature.

Here is the complete, drop-in replacement for `app/api/webhooks/route.ts`:

```ts
import { NextRequest, NextResponse } from "next/server";

// ─── HMAC helpers ────────────────────────────────────────────────────────────

async function verifyGitHubSignature(
  payload: string,
  signature: string | null,
  secret: string,
): Promise<boolean> {
  if (!signature?.startsWith("sha256=")) return false;

  const encoder = new TextEncoder();
  const key = await crypto.subtle.importKey(
    "raw",
    encoder.encode(secret),
    { name: "HMAC", hash: "SHA-256" },
    false,
    ["sign"],
  );

  const mac = await crypto.subtle.sign("HMAC", key, encoder.encode(payload));
  const expected = "sha256=" + Array.from(new Uint8Array(mac))
    .map((b) => b.toString(16).padStart(2, "0"))
    .join("");

  // Constant-time comparison — avoids timing attacks that could leak the secret
  if (expected.length !== signature.length) return false;
  let mismatch = 0;
  for (let i = 0; i < expected.length; i++) {
    mismatch |= expected.charCodeAt(i) ^ signature.charCodeAt(i);
  }
  return mismatch === 0;
}

// ─── Types ───────────────────────────────────────────────────────────────────

interface PushEvent {
  ref: string;
  before: string;
  after: string;
  pusher: { name: string; email: string };
  commits: Array<{
    id: string;
    message: string;
    timestamp: string;
    author: { name: string; username: string };
    added: string[];
    removed: string[];
    modified: string[];
  }>;
  repository: { full_name: string; html_url: string };
}

function parsePushEvent(body: PushEvent) {
  const branch = body.ref.replace("refs/heads/", "");
  const commits = body.commits ?? [];
  return {
    event: "push",
    repo: body.repository.full_name,
    branch,
    pusher: body.pusher.name,
    before: body.before?.slice(0, 7),
    after: body.after?.slice(0, 7),
    commits: commits.map((c) => ({
      sha: c.id.slice(0, 7),
      message: c.message.split("\n")[0],
      author: c.author.username,
      timestamp: c.timestamp,
      files: { added: c.added, removed: c.removed, modified: c.modified },
    })),
  };
}

// ─── Route handler ───────────────────────────────────────────────────────────

export async function POST(req: NextRequest) {
  const secret = process.env.GITHUB_WEBHOOK_SECRET;
  const rawBody = await req.text(); // read as text so we can verify before parsing

  // Skip signature check in development if no secret is set
  if (secret) {
    const sig = req.headers.get("x-hub-signature-256");
    const valid = await verifyGitHubSignature(rawBody, sig, secret);
    if (!valid) {
      console.warn("[webhook] rejected: invalid signature");
      return NextResponse.json({ error: "invalid signature" }, { status: 401 });
    }
  }

  const event = req.headers.get("x-github-event") ?? "unknown";
  const body = JSON.parse(rawBody);

  if (event === "push") {
    const summary = parsePushEvent(body);
    console.log(`\n── push ─ ${summary.repo} ─ ${summary.branch} ──`);
    console.log(`   by: ${summary.pusher}`);
    console.log(`   ${summary.before} → ${summary.after}`);
    for (const c of summary.commits) {
      console.log(`   ${c.sha} ${c.message}`);
      if (c.files.added.length) console.log(`     + ${c.files.added.join(", ")}`);
      if (c.files.modified.length) console.log(`     ~ ${c.files.modified.join(", ")}`);
      if (c.files.removed.length) console.log(`     - ${c.files.removed.join(", ")}`);
    }
    return NextResponse.json(summary);
  }

  console.log(`\n── ${event} ──`);
  console.log(JSON.stringify(body, null, 2));
  return NextResponse.json({ event, received: true });
}
```

**To wire it up in production:**

1. Generate a strong random secret: `openssl rand -hex 32`
2. Add it to Vercel: Settings → Environment Variables → `GITHUB_WEBHOOK_SECRET`
3. In your GitHub repo: Settings → Webhooks → your webhook → Secret field → paste the same value

**Three concepts to lock in:**

1. **Why HMAC, not just a token in the URL?** A secret in the URL (`/api/webhooks?token=abc`) is logged by every proxy, CDN, and server access log between GitHub and you. HMAC signs the *body* with the secret, so the secret never travels over the wire — only the resulting signature does. Even if someone captures the signature, they can't reverse it to learn your secret.

2. **`await req.text()` before `JSON.parse`** — Notice the handler reads the raw body as a string first, *then* parses it. This is mandatory: `crypto.subtle.sign` needs the exact bytes GitHub signed. If you call `req.json()` first, you've already consumed the body stream, and you can't sign something that's been deserialized and re-serialized (whitespace, key order, etc. can differ).

3. **Constant-time comparison prevents timing attacks.** A naive `expected === signature` check leaks how many characters match before the first mismatch — an attacker making thousands of requests can statistically determine your secret one character at a time. The `mismatch |= charA ^ charB` loop always runs to completion regardless of where the mismatch is, giving nothing away.
