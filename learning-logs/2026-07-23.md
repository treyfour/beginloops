**Step 1 — Update `app/api/webhooks/route.ts`** to collect the last 20 payloads:

```ts
import { NextRequest, NextResponse } from "next/server";

// Module-level store: persists across requests within one server instance
const events: { receivedAt: string; payload: unknown }[] = [];

export async function POST(req: NextRequest) {
  const payload = await req.json();
  events.unshift({ receivedAt: new Date().toISOString(), payload });
  if (events.length > 20) events.pop(); // keep at most 20
  return NextResponse.json({ ok: true });
}

export async function GET() {
  return NextResponse.json(events);
}
```

**Step 2 — Test it locally.** Start the dev server (`npm run dev`), then:

```bash
# Send a fake webhook payload
curl -X POST http://localhost:3000/api/webhooks \
  -H "Content-Type: application/json" \
  -d '{"event": "push", "repo": "beginloops"}'

# Fetch the event log
curl http://localhost:3000/api/webhooks
```

You should see your payload echoed back in the GET response.

**Why this matters:** Most webhook tutorials just show the POST handler — they skip the "now what do I do with it?" step. Storing events in the same module that receives them is the simplest possible persistence pattern in Next.js, and once this works you'll understand exactly what it means to "receive a webhook."
