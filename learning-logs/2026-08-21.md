Today's focus: **Webhooks (verifying the sender)**

GitHub sends a `X-Hub-Signature-256` header with every webhook delivery. It's an HMAC-SHA256 digest of the raw request body, keyed with your webhook secret. Your route should compute the same digest and reject anything that doesn't match. Here's the complete, hardened handler:

```ts
// app/api/webhooks/route.ts
import { NextRequest, NextResponse } from "next/server";

// --- HMAC-SHA256 signature verification ---
async function verifySignature(req: NextRequest, rawBody: Uint8Array): Promise<boolean> {
  const secret = process.env.GITHUB_WEBHOOK_SECRET;
  if (!secret) {
    console.warn("[webhooks] GITHUB_WEBHOOK_SECRET not set — skipping verification (dev mode)");
    return true; // allow in dev, block in prod by always setting the var
  }

  const signature = req.headers.get("x-hub-signature-256");
  if (!signature || !signature.startsWith("sha256=")) return false;

  const key = await crypto.subtle.importKey(
    "raw",
    new TextEncoder().encode(secret),
    { name: "HMAC", hash: "SHA-256" },
    false,
    ["sign"]
  );
  const mac = await crypto.subtle.sign("HMAC", key, rawBody);
  const expected = "sha256=" + Array.from(new Uint8Array(mac))
    .map((b) => b.toString(16).padStart(2, "0"))
    .join("");

  // Constant-time comparison prevents timing attacks
  if (expected.length !== signature.length) return false;
  let mismatch = 0;
  for (let i = 0; i < expected.length; i++) {
    mismatch |= expected.charCodeAt(i) ^ signature.charCodeAt(i);
  }
  return mismatch === 0;
}

interface PushEvent {
  ref: string;
  before: string;
  after: string;
  pusher: { name: string; email: string };
  commits: Array<{
    id: string;
    message: string;
    timestamp: string;
    author: { name: string; username: string };
    added: string[];
    removed: string[];
    modified: string[];
  }>;
  repository: { full_name: string; html_url: string };
}

function parsePushEvent(body: PushEvent) {
  const branch = body.ref.replace("refs/heads/", "");
  const commits = body.commits ?? [];
  return {
    event: "push",
    repo: body.repository.full_name,
    branch,
    pusher: body.pusher.name,
    before: body.before?.slice(0, 7),
    after: body.after?.slice(0, 7),
    commits: commits.map((c) => ({
      sha: c.id.slice(0, 7),
      message: c.message.split("\n")[0],
      author: c.author.username,
      timestamp: c.timestamp,
      files: { added: c.added, removed: c.removed, modified: c.modified },
    })),
  };
}

export async function POST(req: NextRequest) {
  // Read raw bytes BEFORE parsing JSON — signature covers the raw body
  const rawBody = new Uint8Array(await req.arrayBuffer());

  // --- 1. Verify the signature ---
  const valid = await verifySignature(req, rawBody);
  if (!valid) {
    console.warn("[webhooks] rejected — invalid signature");
    return NextResponse.json({ error: "Invalid signature" }, { status: 401 });
  }

  // --- 2. Parse and handle ---
  const body = JSON.parse(new TextDecoder().decode(rawBody));
  const event = req.headers.get("x-github-event") ?? "unknown";

  if (event === "push") {
    const summary = parsePushEvent(body);
    console.log(`\n── push ─ ${summary.repo} ─ ${summary.branch} ──`);
    console.log(`   by: ${summary.pusher}`);
    console.log(`   ${summary.before} → ${summary.after}`);
    for (const c of summary.commits) {
      console.log(`   ${c.sha} ${c.message}`);
      if (c.files.added.length) console.log(`     + ${c.files.added.join(", ")}`);
      if (c.files.modified.length) console.log(`     ~ ${c.files.modified.join(", ")}`);
      if (c.files.removed.length) console.log(`     - ${c.files.removed.join(", ")}`);
    }
    return NextResponse.json(summary);
  }

  console.log(`\n── ${event} ──`);
  console.log(JSON.stringify(body, null, 2));
  return NextResponse.json({ event, received: true });
}
```

**Three concepts to lock in:**

1. **Read the raw body before calling `.json()`.** Signature verification runs over the exact bytes GitHub sent. The moment you parse JSON, you've lost the original byte sequence (whitespace, key order). The fix: grab `req.arrayBuffer()` first, store it, verify, then `JSON.parse` the bytes manually.

2. **Constant-time comparison is non-negotiable.** A regular `===` comparison short-circuits on the first mismatch — an attacker can infer byte-by-byte whether their guess is close, making it possible to brute-force the expected value. The XOR loop above takes the same time regardless of where mismatches are. This is a real attack class, not a theoretical one.

3. **`crypto.subtle` is available in Next.js Edge and Node runtimes.** You don't need a library — the Web Crypto API ships in every modern JS runtime, including Vercel's edge functions. HMAC-SHA256 with `importKey` → `sign` is the idiomatic pattern, and it's fast.
