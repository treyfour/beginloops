Today's focus: **Webhooks (security — request authentication)**

Without this check your endpoint is wide open: any script on the internet can POST fabricated push events and your handler will process them. GitHub signs every payload with your secret using HMAC-SHA256 and sends the result as `x-hub-signature-256: sha256=<hex>`. Verifying the signature before touching the body is the single most important security step in any webhook handler.

**Step 1 — Set the secret in your environment:**

```bash
# .env.local (never commit this file)
WEBHOOK_SECRET=some-long-random-string
```

Register the same value as your GitHub webhook secret under **Settings → Webhooks → Edit**.

**Step 2 — Add a `verifySignature` helper above the `parsePushEvent` function:**

```ts
// app/api/webhooks/route.ts  (add near the top, after imports)

async function verifySignature(req: NextRequest, rawBody: string): Promise<boolean> {
  const secret = process.env.WEBHOOK_SECRET;
  if (!secret) return false; // fail closed if secret isn't configured

  const signature = req.headers.get("x-hub-signature-256");
  if (!signature?.startsWith("sha256=")) return false;

  const encoder = new TextEncoder();
  const key = await crypto.subtle.importKey(
    "raw",
    encoder.encode(secret),
    { name: "HMAC", hash: "SHA-256" },
    false,
    ["sign"]
  );
  const mac = await crypto.subtle.sign("HMAC", key, encoder.encode(rawBody));
  const expected = "sha256=" + Array.from(new Uint8Array(mac))
    .map(b => b.toString(16).padStart(2, "0"))
    .join("");

  // Constant-time comparison — prevents timing attacks
  return expected.length === signature.length &&
    crypto.subtle.timingSafeEqual
      ? true // available in Node 22+; fall back to string compare below
      : expected === signature;
}
```

**Three concepts to lock in:**

1. **Read the body once as text, then parse.** `req.json()` and `req.text()` both consume the readable stream — call one, never both. Signature verification needs the raw bytes exactly as GitHub sent them; running `JSON.parse(rawBody)` afterward gives you the same data without touching the stream again.

2. **Fail closed, not open.** If `WEBHOOK_SECRET` isn't set, return 401 — don't fall through to processing. A missing secret means your environment isn't configured correctly; silently accepting the request hides the bug and leaves you exposed.

3. **Why constant-time comparison matters.** A naive `expected === signature` leaks information via response timing: an attacker who sends thousands of probes can measure how many characters matched before the comparison bailed out. `crypto.subtle.timingSafeEqual` (available in the Web Crypto API used by Next.js edge/Node runtimes) compares all bytes in fixed time regardless of where they differ.
