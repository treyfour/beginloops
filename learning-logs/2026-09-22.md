**Add HMAC-SHA256 signature verification to `app/api/webhooks/route.ts` so GitHub's `x-hub-signature-256` header is validated before the payload is processed.**

Today's focus: **Webhooks — request authentication**

Your webhook endpoint currently accepts any POST request from anyone. Real-world webhook security requires verifying that the payload came from GitHub and was not tampered with. GitHub signs every delivery with a secret you set in the webhook settings, and sends the signature in the `x-hub-signature-256` header.

Add this to `app/api/webhooks/route.ts`:

```ts
import { createHmac, timingSafeEqual } from "crypto";

const WEBHOOK_SECRET = process.env.GITHUB_WEBHOOK_SECRET ?? "";

async function verifySignature(req: NextRequest): Promise<boolean> {
  const sig = req.headers.get("x-hub-signature-256");
  if (!sig || !WEBHOOK_SECRET) return false;

  const rawBody = await req.arrayBuffer();
  const expected = "sha256=" + createHmac("sha256", WEBHOOK_SECRET)
    .update(Buffer.from(rawBody))
    .digest("hex");

  try {
    return timingSafeEqual(Buffer.from(sig), Buffer.from(expected));
  } catch {
    return false; // lengths differ — definitely not a match
  }
}
```

Then call it at the top of your `POST` handler:

```ts
export async function POST(req: NextRequest) {
  const verified = await verifySignature(req);
  if (!verified) {
    return NextResponse.json({ error: "unauthorized" }, { status: 401 });
  }
  // ... rest of handler
}
```

> **Note:** `req.arrayBuffer()` reads the raw bytes — you must NOT call `req.json()` before this, because the stream can only be consumed once. Call `verifySignature` first, then parse the body separately.

**Why this matters:** `timingSafeEqual` is the critical detail — a plain `===` comparison is vulnerable to timing attacks where an attacker can infer the correct signature by measuring how long the comparison takes. Using the Node.js crypto primitive eliminates that side-channel. This exact pattern (HMAC + constant-time compare) is used by GitHub, Stripe, Twilio, and virtually every major webhook provider — learn it once and it applies everywhere.
