**Build a live heartbeat display in `app/page.tsx` using `useEffect` and `useState` to poll `/api/cron/heartbeat` every 10 seconds.**

Today's focus: **Hooks — React hooks as the glue between your API and your UI**

You already have the heartbeat endpoint. Now wire it to the screen using two core React hooks:

```tsx
// app/page.tsx
"use client";

import { useEffect, useState } from "react";

type HeartbeatStatus = { ok: boolean; ts: string } | null;

export default function Home() {
  const [status, setStatus] = useState<HeartbeatStatus>(null);

  useEffect(() => {
    const poll = async () => {
      try {
        const res = await fetch("/api/cron/heartbeat");
        const data = await res.json();
        setStatus({ ok: res.ok, ts: data.ts ?? new Date().toISOString() });
      } catch {
        setStatus({ ok: false, ts: new Date().toISOString() });
      }
    };

    poll();
    const id = setInterval(poll, 10_000);
    return () => clearInterval(id); // cleanup on unmount
  }, []);

  return (
    <main style={{ padding: "2rem", fontFamily: "monospace" }}>
      <h1>beginloops</h1>
      {status === null ? (
        <p>Checking heartbeat…</p>
      ) : (
        <p>
          Heartbeat:{" "}
          <strong style={{ color: status.ok ? "green" : "red" }}>
            {status.ok ? "✓ alive" : "✗ down"}
          </strong>{" "}
          — last checked {status.ts}
        </p>
      )}
    </main>
  );
}
```

**Why this matters:** `useEffect` with a cleanup function is the correct pattern for intervals and subscriptions — the `return () => clearInterval(id)` line prevents memory leaks when the component unmounts. This pattern appears everywhere: WebSockets, event listeners, timers. Getting it right here means you understand it for everything else.
