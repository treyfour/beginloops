## Suggested next step

**Create a custom React hook `useHeartbeat` in `app/hooks/useHeartbeat.ts` that polls your heartbeat endpoint on an interval — this teaches you how client-side hooks and server-side crons solve the same problem from different angles.**

Today's focus: **Hooks — wiring browser polling with `useEffect`**

Create `app/hooks/useHeartbeat.ts`:

```ts
import { useState, useEffect } from "react";

export function useHeartbeat(intervalMs = 30_000) {
  const [status, setStatus] = useState<"ok" | "error" | "pending">("pending");
  const [lastChecked, setLastChecked] = useState<Date | null>(null);

  useEffect(() => {
    async function ping() {
      try {
        const res = await fetch("/api/cron/heartbeat");
        setStatus(res.ok ? "ok" : "error");
      } catch {
        setStatus("error");
      }
      setLastChecked(new Date());
    }

    ping(); // fire immediately on mount
    const id = setInterval(ping, intervalMs);
    return () => clearInterval(id); // cleanup prevents memory leaks
  }, [intervalMs]);

  return { status, lastChecked };
}
```

Then use it in `app/page.tsx` to show a live status indicator:

```tsx
import { useHeartbeat } from "./hooks/useHeartbeat";

export default function Home() {
  const { status, lastChecked } = useHeartbeat();
  return (
    <main>
      <p>Heartbeat: {status}</p>
      {lastChecked && <p>Last checked: {lastChecked.toLocaleTimeString()}</p>}
    </main>
  );
}
```

**Why this matters:** Your Vercel cron fires server-side every day, but it's invisible to users. A React hook gives you the browser-side mirror — polling on an interval, cleaning up with `clearInterval` on unmount. The `useEffect` cleanup line is essential: without it, navigating away leaves a dangling interval that keeps firing after the component is gone. This pattern appears in every serious React app that talks to a backend.

**The parallel:** Cron = "ping every 24 hours from the server." `useEffect` + `setInterval` = "ping every 30 seconds from the browser." Same concept, two different runtimes.
