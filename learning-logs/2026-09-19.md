**Create `app/hooks/useHeartbeat.ts` — a custom React hook that polls your heartbeat endpoint every 30 seconds and exposes the live status to any component.**

Today's focus: **Hooks — connecting your backend heartbeat to the frontend**

Your cron and webhook routes are live on the server, but the app's UI still has no visibility into them. A custom hook is the React-idiomatic way to bridge that gap: it encapsulates the polling logic so any component can call `useHeartbeat()` and get the current system status without caring how the data is fetched.

Create `app/hooks/useHeartbeat.ts`:

```ts
"use client";

import { useEffect, useState } from "react";

interface HeartbeatResult {
  status: "ok" | "degraded" | "loading" | "error";
  timestamp: string | null;
  checks: Record<string, string>;
}

export function useHeartbeat(intervalMs = 30_000): HeartbeatResult {
  const [result, setResult] = useState<HeartbeatResult>({
    status: "loading",
    timestamp: null,
    checks: {},
  });

  useEffect(() => {
    let cancelled = false;

    async function ping() {
      try {
        const res = await fetch("/api/cron/heartbeat");
        if (!res.ok) throw new Error(`HTTP ${res.status}`);
        const data = await res.json();
        if (!cancelled) setResult(data);
      } catch {
        if (!cancelled) setResult({ status: "error", timestamp: null, checks: {} });
      }
    }

    ping();
    const id = setInterval(ping, intervalMs);
    return () => {
      cancelled = true;
      clearInterval(id);
    };
  }, [intervalMs]);

  return result;
}
```

Then use it in `app/page.tsx` to show a live status badge:

```tsx
import { useHeartbeat } from "./hooks/useHeartbeat";

export default function Home() {
  const { status, timestamp } = useHeartbeat();

  return (
    <main>
      <p>System status: <strong>{status}</strong></p>
      {timestamp && <p>Last check: {new Date(timestamp).toLocaleTimeString()}</p>}
    </main>
  );
}
```

**Why this matters:** Custom hooks are how React apps stay clean at scale — you pull async side effects (fetching, timers, subscriptions) out of components and into reusable, testable units. The `cancelled` flag and `clearInterval` cleanup prevent stale updates when the component unmounts, which is the most common source of memory leaks in polling hooks. Once you have `useHeartbeat`, you can wire the same pattern to any other endpoint — webhook event counts, cron last-run time, or anything else your backend exposes.
