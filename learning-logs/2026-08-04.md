Today's focus: **Webhooks (Security — Signature Verification)**

Right now your webhook endpoint accepts any POST from anyone. Real-world webhook providers (GitHub, Stripe, Svix) sign every request with a shared secret using HMAC-SHA256 and send the signature in a header like `x-hub-signature-256` or `stripe-signature`. Verifying the signature proves the payload came from the real sender and wasn't tampered with in transit. Without it, anyone who discovers your URL can send fake events.

**Step 1 — Add the secret to `.env.local`:**
```
WEBHOOK_SECRET=your_shared_secret_here
```

**Step 2 — Update `app/api/webhooks/route.ts`:**
```ts
import { createHmac, timingSafeEqual } from "crypto";
import { NextRequest, NextResponse } from "next/server";

function verifySignature(payload: string, signature: string, secret: string): boolean {
  const expected = createHmac("sha256", secret).update(payload).digest("hex");
  // timingSafeEqual prevents timing attacks — always use it for signature checks
  const expectedBuf = Buffer.from(`sha256=${expected}`, "utf8");
  const actualBuf = Buffer.from(signature, "utf8");
  if (expectedBuf.length !== actualBuf.length) return false;
  return timingSafeEqual(expectedBuf, actualBuf);
}

export async function POST(req: NextRequest) {
  const rawBody = await req.text(); // must be raw text, not parsed JSON
  const signature = req.headers.get("x-hub-signature-256") ?? "";
  const secret = process.env.WEBHOOK_SECRET ?? "";

  if (!verifySignature(rawBody, signature, secret)) {
    console.warn("[webhook] rejected: invalid signature");
    return NextResponse.json({ error: "Unauthorized" }, { status: 401 });
  }

  const payload = JSON.parse(rawBody);
  console.log("[webhook] received:", payload);
  return NextResponse.json({ ok: true });
}
```

**Why `timingSafeEqual` matters:** A normal string comparison (`===`) short-circuits on the first mismatched character — an attacker can measure how long your server takes to reject a guess and use that timing to infer the correct signature one byte at a time. `timingSafeEqual` always compares every byte in constant time, closing that side channel.

**Why `req.text()` not `req.json()`:** The HMAC is computed over the raw bytes the sender sent. Parsing JSON first reformats the body (whitespace, key order may change), producing a different hash. Always read the raw body before parsing.

**Test it with curl:**

```bash
# Generate a valid signature
SECRET="your_shared_secret_here"
PAYLOAD='{"event":"ping"}'
SIG="sha256=$(echo -n "$PAYLOAD" | openssl dgst -sha256 -hmac "$SECRET" | awk '{print $2}')"

# Valid request (should return 200)
curl -X POST http://localhost:3000/api/webhooks \
  -H "Content-Type: application/json" \
  -H "x-hub-signature-256: $SIG" \
  -d "$PAYLOAD"

# Tampered request (should return 401)
curl -X POST http://localhost:3000/api/webhooks \
  -H "Content-Type: application/json" \

```
