Today's focus: **Hooks (React hooks as the glue between your backend APIs and the UI)**

Your heartbeat route already returns useful data (`status`, `timestamp`, `checks`). A custom hook is how you bring that data into any React component without re-writing the fetch logic every time you need it. This is one of the most common patterns in Next.js apps — understanding it unlocks real-time UI updates for any API you build.

**Step 1 — Create the hook:**

```ts
// app/hooks/useCronStatus.ts
"use client";

import { useEffect, useState } from "react";

export interface HeartbeatResult {
  status: "ok" | "degraded";
  timestamp: string;
  durationMs: number | null;
  checks: { webhookEndpoint: "ok" | "unreachable" };
}

export function useCronStatus(intervalMs = 30_000) {
  const [data, setData] = useState<HeartbeatResult | null>(null);
  const [isLoading, setIsLoading] = useState(true);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    let cancelled = false;

    async function poll() {
      try {
        const res = await fetch("/api/cron/heartbeat");
        if (!res.ok) throw new Error(`HTTP ${res.status}`);
        const json: HeartbeatResult = await res.json();
        if (!cancelled) { setData(json); setError(null); }
      } catch (e) {
        if (!cancelled) setError(e instanceof Error ? e.message : "fetch failed");
      } finally {
        if (!cancelled) setIsLoading(false);
      }
    }

    poll();
    const id = setInterval(poll, intervalMs);
    return () => { cancelled = true; clearInterval(id); };
  }, [intervalMs]);

  return { data, isLoading, error };
}
```

**Step 2 — Use it in `app/page.tsx`:**

```tsx
// app/page.tsx
"use client";
import { useCronStatus } from "./hooks/useCronStatus";

export default function Home() {
  const { data, isLoading } = useCronStatus();

  const dot = isLoading ? "⏳" : data?.status === "ok" ? "🟢" : "🔴";
  const label = isLoading
    ? "checking…"
    : `${data?.status ?? "unknown"} · ${new Date(data?.timestamp ?? "").toLocaleTimeString()}`;

  return (
    <main style={{ padding: "2rem", fontFamily: "monospace" }}>
      <h1>beginloops</h1>
      <p>{dot} webhook health: {label}</p>
    </main>
  );
}
```

**Three concepts to lock in:**

1. **`useEffect` + `setInterval` = polling.** The cleanup function (`return () => { clearInterval(id) }`) is critical — without it, every re-render leaks a new timer. The `cancelled` flag prevents a late-arriving fetch from updating state on an unmounted component (a common React bug).

2. **A custom hook is just a function that calls other hooks.** `useCronStatus` calls `useState` and `useEffect` internally — that's the whole pattern. By wrapping them, any component that needs heartbeat data just calls `useCronStatus()` and gets the result without caring how the fetch works.

3. **`"use client"` tells Next.js this component/hook runs in the browser.** Without it, `useEffect` and `useState` are unavailable (the file would be treated as a Server Component). Data-fetching hooks always need this directive.
