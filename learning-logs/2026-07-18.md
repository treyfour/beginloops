## Suggested next step
**Persist the last heartbeat result so the UI can display it.**

The heartbeat cron already produces a useful payload (`{ status, timestamp, checks }`), but it only writes to `console.log`, which disappears after the serverless function exits. Wire it to a module-level cache and expose it via a new `/api/status` route, then poll that route from `app/page.tsx` using `useEffect`.

**1. Add a `/api/status` route** (`app/api/status/route.ts`):

```ts
import { NextRequest, NextResponse } from "next/server";

interface HeartbeatPayload {
  status: "ok" | "degraded";
  timestamp: string;
  checks: { webhookEndpoint: "ok" | "unreachable" };
}

// Module-level cache — persists across requests within a warm instance
let lastHeartbeat: HeartbeatPayload | null = null;

export async function GET() {
  return NextResponse.json(lastHeartbeat ?? { status: "unknown", timestamp: null });
}

// The heartbeat cron will POST here to update the cache
export async function POST(req: NextRequest) {
  lastHeartbeat = await req.json();
  return NextResponse.json({ ok: true });
}
```

**2. Update `/api/cron/heartbeat/route.ts`** to POST its result to `/api/status` before returning:

```ts
// After computing `payload`, before the final return:
await fetch(`${base}/api/status`, {
  method: "POST",

  body: JSON.stringify(payload),

```

**3. Poll it from `app/page.tsx`** using a `useEffect`:

```tsx
"use client";
import { useEffect, useState } from "react";

export default function Home() {
  const [status, setStatus] = useState<{ status: string; timestamp: string | null } | null>(null);

  useEffect(() => {
    const poll = () =>
      fetch("/api/status")
        .then((r) => r.json())
        .then(setStatus)
        .catch(() => {});

    poll(); // fetch immediately on mount
    const id = setInterval(poll, 30_000); // then every 30 seconds
    return () => clearInterval(id); // cleanup on unmount
  }, []);

  return (
    <main>
      <h1>beginloops</h1>
      {status ? (
        <p>
          Heartbeat: <strong>{status.status}</strong>
          {status.timestamp && <> · last run {new Date(status.timestamp).toLocaleString()}</>}
        </p>
      ) : (
        <p>Loading status…</p>
      )}
    </main>
  );
}
```

**Why this matters:** This closes the loop on everything you have built. The cron now *writes* observable state; the UI *reads* it on a heartbeat of its own (the 30 s `setInterval`). You learn three things at once: (1) how a serverless cron function communicates with the rest of the app, (2) the `useEffect` cleanup pattern that prevents memory leaks when the component unmounts, and (3) why module-level caches work but reset on cold start — which naturally leads to the next real problem: reaching for Vercel KV or a database when you need persistence that survives restarts.
