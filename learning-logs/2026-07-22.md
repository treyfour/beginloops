**Create a custom React hook `app/hooks/useHeartbeat.ts` that fetches `/api/cron/heartbeat` on mount, then use it in `app/page.tsx` to show a live health badge — this makes your heartbeat visible and teaches the core React hooks pattern in the context of code you already built.**

Create `app/hooks/useHeartbeat.ts`:
```ts
import { useEffect, useState } from "react";

interface HeartbeatResult {
  status: "ok" | "degraded";
  timestamp: string;
  checks: { webhookEndpoint: "ok" | "unreachable" };
}

export function useHeartbeat() {
  const [data, setData] = useState<HeartbeatResult | null>(null);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    fetch("/api/cron/heartbeat")
      .then((r) => r.json())
      .then((d) => setData(d))
      .finally(() => setLoading(false));
  }, []);

  return { data, loading };
}
```

Then add a status badge to `app/page.tsx`:
```tsx
import { useHeartbeat } from "@/app/hooks/useHeartbeat";

// inside your component:
const { data, loading } = useHeartbeat();

// render:
<span className={data?.status === "ok" ? "text-green-600" : "text-red-500"}>
  {loading ? "checking…" : data?.status ?? "unknown"}
</span>
```

Wiring `useEffect` + `useState` to fetch your own API is the fundamental React pattern for all data-driven UIs — and doing it with `/api/cron/heartbeat` means you're practicing **hooks** (the fourth learning topic) while making your existing **heartbeat** endpoint actually useful.
